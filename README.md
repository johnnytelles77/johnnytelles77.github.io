## Getting Started

### Requirements

- Node.js 20 or later
- npm

### Installation

```bash
git clone https://github.com/johnnytelles77/johnnytelles77.github.io.git

cd johnnytelles77.github.io

npm ci
```

### Run Locally

```bash
npm run dev
```

### Lint

```bash
npm run lint
```

### Production Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## CI/CD

Pull Requests targeting `main` are validated using
GitHub Actions.

CI runs:

- Dependency installation
- ESLint
- Production build

Deployment to GitHub Pages is triggered by
a push to the `main` branch.
